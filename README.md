# 收息股每日盯盘

用 GitHub Actions 每个交易日收盘后自动抓行情，判断是否触发条件，通过 Server酱 推到微信。不依赖任何自己的电脑或客户端。

## 这是什么

- **每天 15:10（北京时间，周一到周五）** 自动运行一次
- 抓 601398 / 600900 / 588000 的收盘价
- 判断四条规则（可自己改）：跌破目标价 / 阶梯破位 / 股息率达到阈值 / 单日大跌
- 股息率**自动算**：脚本自己抓东方财富的分红数据，不填任何数字
- 把结果整理成一张表，推到微信
- 运行状态写回 `state/state.json`，用于去重，同时让定时任务保持存活

## 目录结构

```
.github/workflows/daily-check.yml   定时任务定义（什么时候跑、跑什么）
scripts/check_dividend_stocks.py    主脚本（抓数据 + 判断 + 推送）
state/state.json                    运行状态（自动生成，不用手改）
```

## 当前的阈值设置

| 标的 | 规则 | 参数 |
| --- | --- | --- |
| 工商银行 601398 | 跌破 8.00 元 | `target_price: 8.00` |
| 长江电力 600900 | TTM 股息率 ≥ 4%（对应 25.00 元） | `target_price: 25.00`、`target_yield: 4.0` |
| 科创50ETF 588000 | 三档阶梯 1.22 / 1.12 / 1.03，破一档报一次 | `tiers: [1.22, 1.12, 1.03]` |

## 股息率是怎么算出来的

脚本会去东方财富的分红数据接口（`RPT_SHAREBONUS_DET`）拉取每只标的的分红记录，按**除权日在近 12 个月内**的每股派息（含税）加总，再除以现价：

```
股息率(TTM) = 近 12 个月每股派息合计 ÷ 现价 × 100%
```

- 分红数据缓存在 `state/state.json` 的 `dividend` 字段里，**7 天刷新一次**，不会每次运行都请求
- 推送消息底部会列出用到的每次派息日期与金额，方便你核对
- ETF 没有"每股分红"概念，这一栏显示「—」
- 想强制指定某个数：在该标的配置里填 `dps`，手填值优先于自动计算

> 举例（2026-11-07 实测）：工商银行近 12 个月派息 3 次合计 0.4614 元，8.44 元对应 5.47%；长江电力派息 2 次合计 1.0000 元，29.91 元对应 3.34%。

## 我该改哪里

只改 `scripts/check_dividend_stocks.py` 顶部的配置区：

```python
WATCHLIST = [
    # 单一目标价
    {"code": "601398", "name": "工商银行", "secid": "1.601398",
     "target_price": 8.00, "dps": None},
    # 阶梯买入位（破一档报一次，破过的不重复报）
    {"code": "588000", "name": "科创50ETF", "secid": "1.588000",
     "target_price": None, "dps": None, "tiers": [1.22, 1.12, 1.03]},
]
TARGET_YIELD = None    # 全局股息率门槛（%）；None = 只显示不提醒
DROP_ALERT = -2.0      # 单日跌 ≥ 2% 提醒
MODE = "daily"         # daily 每天推一条；signal 只在触发时推
```

- `target_price`：目标买入价，填 `None` 表示不按单一价格判断
- `tiers`：阶梯买入位，按价格从高到低写；每破一档推一次，同档不会重复推
- `dps`：手工指定每股分红（元），**一般不用填**，留 `None` 就是自动按分红数据算 TTM
- `target_yield`：该标的的股息率门槛（%）。写了才会因股息率达标而提醒，不写只在表里显示
- 改完直接提交，下一次运行生效，不需要重新部署

> 想重置阶梯记录（比如希望破过的档位再报一次）：编辑 `state/state.json`，把 `tiers` 里对应标的的数组清空即可。
